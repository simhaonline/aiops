# About SIMHA AiOps

SIMHA AiOps Manager Suite `1.0.1` is a collection of Ubuntu 24.04 lifecycle managers for system hardening, developer runtimes, AI agents, AI gateways, networking, TLS edge services, and cross-manager verification.

The project intentionally separates **manager deployment** from **runtime deployment**. The one-line bootstrap safely installs manager commands; operators explicitly install or repair individual runtimes afterward.
